# TTT Expansion v1.0.0 — Novo Menu com Texturas (beta)

Esta versão **modifica o código do plugin PSP/PPSSPP** e redesenha a interface usando um fundo e fonte renderizados por texturas da GPU. **Não é apenas um mockup.**

- 3 Gokus: Goku Início (ID 00), Goku Mid (ID 01), Goku Mid SSJ (ID 02)
- Quatro trajes para cada um e seleção dos quatro jogadores (1P a 4P)
- Guia: `LEIA_PRIMEIRO_MENU_V1000.md`
- Visual: `TTT_EXPANSION/ui/PREVIEW_MENU_REFEITO.png`
- Textura HD editável: `TTT_EXPANSION/ui/menu_bg_HD.png` (1440x816)
- Plugin: compile pelo GitHub Actions, gerando `TTT-Expansion-PRX-V1000`.

**Atenção:** o pacote contém os fontes e texturas prontos para compilar. Nenhum `.prx` foi compilado neste ambiente (sem PSPSDK). É necessário compilar via GitHub Actions e testar no PPSSPP. A ISO/PACKFILE já modificado não precisa ser reconstruído.
